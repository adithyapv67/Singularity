# Singularity · The Astronomical Society of BMSCE

Official website of Singularity, the astronomy club of BMS College of Engineering.

## Features
- Dynamic Celestial Space Canvas with stars, constellations, and falling meteors
- Club Mission, Rover Engineering & Astronomy initiatives
- Events, Workshops, Observations, and Reach metrics
- Technical Team and Core Members directory
- Interactive stargazing and contact sections

## Setup
Simply open `index.html` in any modern web browser or host on GitHub Pages.
